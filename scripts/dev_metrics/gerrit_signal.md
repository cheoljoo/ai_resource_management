# Gerrit 리뷰·댓글·병합·제출자 수집

[gerrit_signal.py](gerrit_signal.py)는 `uv run`으로 실행하며 `requests`를 자동 준비한다.
기존 외부 자격증명 모듈을 재사용하고 비밀 값은 출력하지 않는다.

## 실행

이 문서가 있는 디렉터리에서 실행:

```sh
make gerrit
make gerrit GERRIT_LIMIT=0
make gerrit GERRIT_SERVERS=na GERRIT_LIMIT=50 SINCE_DAYS=90
make combine
make test-gerrit
uv run gerrit_signal.py --server na --limit-per-server 3
```

기본값은 최근 180일에 **갱신된 change 중 서버당 최대 500개**다. 기존 범위를 유지하되
페이지네이션으로 서버의 페이지 크기 제한을 처리한다. `GERRIT_LIMIT=0`은 기간 내 모든
접근 가능한 change를 조회하므로 서버 규모에 따라 API 호출과 시간이 크게 증가한다.
상한 도달 서버는 JSON의 `truncated_servers`와 CLI·결합 리포트 경고에 표시한다.
이 경우 해당 기간 전체를 수집한 것이 아니다.

## change별 저장 내용

| 필드 | 의미 |
| --- | --- |
| `status`, `merged` | 실제 Gerrit 상태. `MERGED`만 병합 완료로 판단 |
| `owner` | change 소유자. submitter와 혼동하지 않음 |
| `submitter`, `submitted`, `submitter_known` | Gerrit이 제공한 실제 제출자와 제출 시각. 누락 시 unknown, owner로 추정하지 않음 |
| `votes` | 현재 patch set의 라벨별 투표 스냅샷. 값 0도 원래 응답대로 보관하나 투표 집계에서는 제외 |
| `reviewers`, `reviewer_updates` | 현재 reviewer/CC 명단 및 추가·삭제 이력. 지정됐다는 사실만으로 리뷰했다고 세지 않음 |
| `messages` | 모든 change-level 메시지의 ID, 작성자/실제 작성자, 시각, patch set 번호, tag |
| `comments` | **모든 patch set**의 공개 파일/라인/patch-set 댓글. ID·작성자·시각·파일·라인·범위·부모 댓글·해결 여부 |
| `robot_comments` | 별도 robotcomments API의 메타데이터. 미지원/미노출 시 null 및 서버 목록 경고 |
| `unresolved_comment_count` | Gerrit이 제공할 때 저장하는 미해결 스레드 수. 댓글 개수와 다름 |

메시지는 자동화·시스템 이벤트도 포함하며, 일반 댓글과 중복 합산하지 않는다.
현재 투표와 메시지 메타데이터는 제공하지만 **과거 모든 투표 변경 값의 이벤트 이력을
복원하는 것은 아니다**. 취소/교체된 투표 값은 현재 라벨 스냅샷에 남지 않을 수 있다.
비공개 draft와 접근 권한 밖의 댓글은 수집하지 않는다.

## 집계 및 결합 리포트

| JSON counter | 리포트 | 집계 |
| --- | --- | --- |
| `person_total` | `g_owner` | 선택된 change의 owner 건수. 기존 호환 의미 유지 |
| `reviewer_total` | `g_review` | 0이 아닌 현재 투표, 최근 댓글 또는 리뷰 메시지가 있는 고유 change 수. owner 자신의 feedback 제외 |
| `vote_total` | JSON 전용 | 현재 라벨 중 0이 아닌 투표 수. 과거 투표 이벤트 수가 아님 |
| `comment_total` | `g_comment` | 기간 내 공개 댓글 수 |
| `message_total` | `g_message` | 기간 내 change-level 메시지 수. 시스템 이벤트 포함 |
| `robot_comment_total` | JSON 전용 | 기간 내 robot 댓글 수 |
| `merged_owner_total` | `g_merged` | 선택된 change 중 현재 MERGED 상태인 owner별 건수 |
| `submitter_total` | `g_submit` | 기간 내 submitted된 MERGED change의 실제 submitter별 건수 |

댓글·메시지·submitter의 **집계**는 이벤트 시각을 기준으로 기간을 제한한다.
change별 메타데이터 목록은 과거 이력도 보관하므로 목록 길이와 기간 집계가 다를 수 있다.
과거에 병합됐으나 최근 갱신된 change는 `g_merged`에 포함되지만 `g_submit`에는 포함되지 않는다.
투표 날짜가 없는 서버도 있으므로 리뷰 집계에 쓰는 현재 투표는 기간 내 투표 행위의 증거가 아니다.

기계 계정이 일반 댓글·라벨·리뷰 메시지를 작성할 수도 있다. `g_review`는 사람 여부를
검증한 지표가 아니다. 알려진 Gerrit upload 자동 메시지는 리뷰 근거에서 제외하며
`autogenerated:gerrit:review`는 리뷰 게시 행위로 포함한다.
이메일과 username이 없으면 서버별 account ID를 사용해 다른 서버의 동명 ID와 구분한다.
구버전 JSON에 새 counter가 없으면 결합 리포트는 0 대신 `N/A`를 표시한다.

## 개인정보 및 오류 처리

2026-09-15 사용자 확인에 따라, 표준 REST 응답에 포함된 댓글·메시지 본문은
**메타데이터로 변환하면서 버리고 저장·출력하지 않는다**. 코드·리뷰 본문 분석은 하지 않는다.
JSON에는 허용된 필드만 복사하며 robot fix suggestion의 코드도 저장하지 않는다.
개인별 성과 비교·평가가 아닌 전문가 라우팅에만 사용한다.

필수 API 인증·권한·네트워크·파싱 오류는 실패 코드로 중단하며 기존 JSON을 덮어쓰지 않는다.
robotcomments의 404/405만 미지원/미노출로 표시하고 나머지는 실패 처리한다.
수집은 실행 중 변경될 수 있는 Gerrit 데이터를 읽는 것이므로 트랜잭션 스냅샷은 아니다.
